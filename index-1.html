1. ¿QUÉ ES EL PROTOCOLO IPv4?

El Protocolo de Internet versión 4 (IPv4) es el sistema principal encargado de identificar cada dispositivo conectado a una red y guiar los paquetes de datos desde un origen hasta un destino. Funciona como un "sistema postal digital": asigna una dirección única (dirección IP) a cada equipo para que la información sepa exactamente a dónde llegar.

Opera en la Capa de Red (Capa 3) del modelo OSI y se caracteriza por ser un protocolo sin conexión y de mejor esfuerzo (best-effort), lo que significa que envía los paquetes de forma independiente buscando la ruta más rápida, dejando la verificación de errores a protocolos superiores como TCP.

2. ESTRUCTURA DE UNA DIRECCIÓN IPv4

Una dirección IPv4 está compuesta por 32 bits divididos en cuatro bloques de 8 bits llamados octetos. Para que sea fácil de leer, se escribe en formato decimal separado por puntos, donde cada número va del 0 al 255 (ejemplo: 192.168.1.10).

  • Porción de Red: Identifica la red específica a la que pertenece el dispositivo (similar al nombre de una calle).
  • Porción de Host: Identifica al dispositivo exacto dentro de esa red (similar al número de casa).
  • Máscara de Subred: Indica qué parte de la dirección IP corresponde a la red y qué parte al dispositivo (ejemplo: 255.255.255.0).

3. CLASES DE DIRECCIONES IPv4

Tradicionalmente, las direcciones IPv4 se organizan en cinco clases según el tamaño de la red y su propósito:

Clase Rango 1er Octeto Máscara por Defecto Uso Principal
Clase A 1 – 126 255.0.0.0 (/8) Redes gigantescas (Proveedores de Internet)
Clase B 128 – 191 255.255.0.0 (/16) Redes medianas y grandes (Universidades, empresas)
Clase C 192 – 223 255.255.255.0 (/24) Redes pequeñas (Hogares, oficinas, locales)
Clase D 224 – 239 No aplica Multicast (transmisión simultánea a grupos)
Clase E 240 – 255 No aplica Investigación y pruebas experimentales

4. DIRECCIONES PÚBLICAS VS. PRIVADAS

No todas las direcciones IP tienen el mismo alcance. Para aprovechar mejor los recursos, se dividen en dos tipos fundamentales:

  • IP Públicas: Son únicas en todo el mundo y permiten navegar directamente en Internet. Las asignan los proveedores de servicios (ISP).
  • IP Privadas: Se usan únicamente dentro de redes internas (casas, laboratorios, empresas) y no son visibles directamente en Internet. Sus rangos reservados son:
    • 10.0.0.0 a 10.255.255.255 (Clase A)
    • 172.16.0.0 a 172.31.255.255 (Clase B)
    • 192.168.0.0 a 192.168.255.255 (Clase C)

5. PARTES DEL PAQUETE (ENCABEZADO IPv4)

Cada vez que se envía información, IPv4 le coloca una etiqueta inicial llamada encabezado (mínimo 20 bytes) que contiene los datos esenciales para el viaje:

  • Versión: Indica que es versión 4 (en binario 0100).
  • TTL (Tiempo de Vida): Evita que un paquete quede dando vueltas infinitamente si hay un error en la red; cada router que cruza le resta 1 hasta llegar a cero.
  • Protocolo: Señala qué tipo de datos van dentro (por ejemplo: 6 para TCP, 17 para UDP).
  • IP Origen e IP Destino: Las direcciones de 32 bits de quién envía y quién recibe.

6. AGOTAMIENTO Y SOLUCIONES ACTUALES

Como IPv4 usa 32 bits, solo existen aproximadamente 4.294 millones de direcciones posibles. Debido al crecimiento masivo de teléfonos, computadoras y dispositivos inteligentes, estas direcciones se agotaron. Para resolverlo se aplican tres soluciones clave:

  • NAT (Traducción de Direcciones de Red): Permite que decenas de dispositivos con IP privadas en una casa u oficina salgan a Internet compartiendo una sola IP pública.
  • Subnetting y CIDR: Divide redes grandes en subredes más pequeñas y exactas para no desperdiciar direcciones.
  • IPv6: Es el sucesor moderno de 128 bits, capaz de ofrecer una cantidad prácticamente ilimitada de direcciones.
